# Jay Lab 홈페이지

주소: https://jaylab-hyu.github.io

## 어디를 고치면 되나요
| 바꾸고 싶은 것 | 파일 |
|---|---|
| 소식, 구성원, 논문, 홈 슬라이드 사진 | `assets/data.js` |
| 연구 소개 | `research.html` |
| PI 소개 | `pi.html` |
| 모집 안내 | `join.html` |
| 주소, 이메일, 전화 | `contact.html` |
| 색상, 글꼴 | `assets/style.css` 맨 위 `:root` |

## 수정 방법
1. GitHub 저장소에서 파일을 클릭합니다.
2. 오른쪽 위 연필 아이콘을 눌러 수정합니다.
3. Commit changes를 누르면 1~2분 뒤 사이트에 반영됩니다.
